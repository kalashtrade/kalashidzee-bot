# kalashidzee trade — бот сигналов по пробою флэта

Бот каждые 15 минут проверяет BTC, ETH, SOL, HYPE, BNB, XRP, LINK, AVAX на бирже OKX (публичные данные, ключи не нужны)
и присылает в Telegram: вход, стоп, три тейка, причину сигнала и итог сделки. Работает бесплатно в GitHub Actions, компьютер включать не надо.

## Что считается сигналом
1. За последние 24 часа цена ходила во флэте не шире 5%.
2. Свеча 15м закрылась за потолком (лонг) или полом (шорт) минимум на 0,10%.
3. Объём этой свечи в 1,5 раза выше среднего, закрытие сильное (верхние 35% свечи для лонга).
4. Тренд совпадает: лонг выше EMA200, шорт ниже.
5. Стоп за уровнем на 0,5 ATR, не меньше 0,3% и не больше 3% от входа.
6. Цели 1R, 2R, 3R: 50% / 30% / 20%. После TP1 стоп в безубыток.
7. Монета должна иметь суточный оборот от 50 млн USDT. Мемкоинов в списке нет.

Это реконструкция по скринам канала, а не проверенная система. Сначала запусти бэктест и посмотри цифры.

## Установка за 10 минут
**1. Telegram-бот.** В Telegram найди @BotFather → `/newbot` → придумай имя → получишь токен вида `123456:ABC...`.
Открой своего нового бота и нажми Start. Потом узнай свой chat id: напиши @userinfobot, он ответит числом (это `TELEGRAM_CHAT_ID`).
Если хочешь сигналы в канал или группу: добавь бота админом и возьми id канала (`-100...`).

**2. GitHub.** Зарегистрируйся на github.com → New repository → название любое, **Public** (так Actions бесплатны без лимита минут; токены останутся скрытыми в Secrets) → загрузи сюда все файлы из этой папки (Add file → Upload files). Папку `.github` тоже. Если не видишь её в проводнике, включи показ скрытых файлов.

**3. Секреты.** Repo → Settings → Secrets and variables → Actions → New repository secret:
- `TELEGRAM_BOT_TOKEN` = токен от BotFather
- `TELEGRAM_CHAT_ID` = твой id

Необязательно, на вкладке Variables: `DEPOSIT_USD` (например 1000) и `RISK_PCT` (например 1). Тогда в сигнале появится размер позиции.

**4. Запуск.** Вкладка Actions → разреши workflows → выбери `signals` → Run workflow. Дальше запускается сам каждые 15 минут. Сигнала может долго не быть: это нормально, флэт с пробоем на объёме бывает не каждый день.

**5. Бэктест.** Actions → `backtest` → Run workflow (days = 90). В логе будет винрейт, средний R, просадка. Файл со сделками скачивается из Artifacts. Те же параметры можно крутить: `--no-trend`, `--max-range 6`, `--vol-mult 1.2`.
Локально: `pip install -r requirements.txt` → `python backtest.py --days 90`.

## Важно
- Бот шлёт только сигналы, сам не торгует и ключи биржи не просит.
- GitHub может опаздывать с запуском на несколько минут, поэтому в сообщении указана цена на момент отправки. Если цена ушла далеко от входа, сделку лучше пропустить.
- Если бот замолчал: Actions → signals → Enable workflow (GitHub отключает расписание в неактивных репозиториях через 60 дней).
- Приватный репозиторий: поставь `*/30` в `signals.yml`, иначе бесплатные минуты закончатся.
- Если у монеты нет контракта на OKX, она тихо пропускается. Список меняется в `config.py`.
- Проверка логики без интернета: `python tests.py`.
- Не финансовая рекомендация. Торговля с плечом может привести к потере депозита.
